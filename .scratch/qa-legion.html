QA测试军团

Skill：gaming-qa-ledger 用途：测试报告 / Bug单 / 台账 浏览器执行：主 Agent 单线程

触发方式

以后可以直接说：$gaming-qa-ledger 处理这个需求，走测试军团流程，输出 HTML 报告、Bug单并更新台账。

已按官方 custom agents 方式创建本地 agent 文件，位置：C:\Users\tolle\.codex\agents\qa-*.toml。新建后通常需要重开 Codex 会话才会被当前会话识别。

智能体分工

智能体 职责 是否可并行
资源管理 Agent 维护测试资源卡片：H5/后台地址、需求文档、路径、站点/商户、报告目录、截图目录和敏感操作边界；不判断 bug。 可并行
需求提取 Agent 从截图、产品回复、原型、后台路径提取需求事实和验收规则。 可并行
疑问闸门 Agent 只提出会影响通过/失败判断的问题，过滤掉泛化实现问题。 可并行
用例设计 Agent 把确认后的规则转成用例、边界和证据要求。 可并行
浏览器执行 Agent 由主 Agent 执行后台/H5只读操作、截图和结果判断。 不可并行
Bug单 Agent 根据已确认失败生成开发可读的 bug 单 HTML。 可并行
台账 Agent 更新 qa-index.html：状态、问题数、报告链接、回归状态。 可并行
