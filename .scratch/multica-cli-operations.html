Multica CLI 操作手册

来源：$ask-matt 路由后沉淀 环境：Multica Cloud + Windows 本机 daemon 最后更新：2026-07-08

使用原则

先查 help 以本机 multica --help 和 multica <command> --help 为准。README 可能滞后，本机 CLI 是当前可执行能力清单。
云托管路径 当前不是 self-host，使用 multica setup cloud。只有本机自建服务才用 multica setup self-host。
结构化输出 查询和创建类命令优先加 --output json，方便复制 ID、校验成员和自动化。
敏感信息 不要把 token、密码、OTP、验证码、MCP secret 写进命令历史。涉及 secret 时用 --custom-env-stdin、--custom-env-file 或 --mcp-config-stdin。

基础配置与状态检查

连接 Multica Cloud

multica setup cloud

这个命令会配置 https://api.multica.ai 和 https://multica.ai，打开浏览器登录，并启动本机 daemon。

查看配置

multica config show

查看 workspace / runtime / daemon

multica workspace list --output json
multica runtime list --output json
multica daemon status

Skill 操作

目的 命令
查看 workspace skills multica skill list --output json
用本地文件创建 skill multica skill create --name gaming-qa-ledger --description "..." --content-file .scratch\multica-gaming-qa-ledger-skill.md --output json
更新 skill 内容 multica skill update <skill-id> --content-file .scratch\multica-gaming-qa-ledger-skill.md --description "..." --output json
读取 skill 详情 multica skill get <skill-id> --output json

Agent 操作

查看 agents

multica agent list --output json

创建 agent

multica agent create `
  --name "QA资源管理员" `
  --description "维护测试资源清单：前后台地址、需求文档、路径、账号标识、报告目录和敏感操作边界。" `
  --instructions "你是 QA资源管理员。..." `
  --runtime-id <runtime-id> `
  --visibility workspace `
  --thinking-level medium `
  --output json

更新 agent

multica agent update <agent-id> `
  --instructions "新的 instructions" `
  --description "新的描述" `
  --output json

绑定 skill

multica agent skills add <agent-id> --skill-ids <skill-id> --output json
multica agent skills list <agent-id> --output json

注意：创建 agent 必须有 --runtime-id。先用 multica runtime list --output json 找在线 runtime。

Squad 操作

查看 squads

multica squad list --output json

创建 squad

multica squad create `
  --name "QA测试军团" `
  --description "博彩/游戏 H5 + 后台管理系统 QA 小队：需求澄清、测试设计、低敏浏览器执行、HTML bug 单、QA 台账。" `
  --leader <leader-agent-id-or-name> `
  --output json

添加成员

multica squad member add <squad-id> `
  --member-id <agent-id> `
  --type agent `
  --role "资源管理" `
  --output json

校验 squad

multica squad get <squad-id> --output json
multica squad member list <squad-id> --output json

常见问题

现象 处理
No server configured. Run 'multica setup' first. 云托管执行 multica setup cloud，self-host 才执行 multica setup self-host。
workspace ID is required 先 multica workspace list，再 multica workspace switch <workspace-id-or-slug>；或命令加 --workspace-id。
沙箱里提示无法连接服务器 需要在允许外部网络的环境执行 Multica 命令；本次用的是已授权的 multica 前缀。
UI 没看到新 squad/agent 先用 multica squad get 或 multica agent list 校验。CLI 已存在但 UI 没刷新时，刷新 Multica 桌面应用。
