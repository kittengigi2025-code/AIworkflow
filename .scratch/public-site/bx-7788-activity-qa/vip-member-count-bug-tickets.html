BUG-001：成员数量为 0 时仍显示为蓝色可点击样式

建议级别 P1
影响范围 VIP管理 / 查看会员 / 成员数量列
前置条件 后台已登录，进入 福利中心 / VIP管理 / 查看会员，当前站点为 巴西站-测试，商户号 888。
复现步骤
  1. 进入 福利中心 / VIP管理。
  2. 切换到 查看会员 tab。
  3. 查看 VIP10 行的成员数量。
  4. 观察成员数量 0 的样式，并点击该数字。
期望结果 成员数量为 0 时不可点击，不应表现为蓝色 link 或手型指针，点击后不出现查看会员弹框。
实际结果 VIP10 成员数量为 0，点击后确实不出现弹框；但该数字仍使用 ant-btn ant-btn-link， 颜色为 rgb(24, 144, 255)，鼠标指针为 pointer，视觉上仍像可点击入口。

BUG-002：成员明细弹框顶部 VIP等级筛选值与被点击等级不一致

建议级别 P1
影响范围 VIP管理 / 查看会员 / 成员明细弹框
前置条件 后台已登录，进入 福利中心 / VIP管理 / 查看会员，当前站点为 巴西站-测试，商户号 888。
复现步骤
  1. 进入 福利中心 / VIP管理 / 查看会员。
  2. 点击 VIP1 的成员数量。
  3. 观察成员明细弹框顶部 VIP等级 筛选值和表格行内 VIP等级。
  4. 关闭弹框。
  5. 点击 VIP2 的成员数量。
  6. 再次观察成员明细弹框顶部 VIP等级 筛选值和表格行内 VIP等级。
期望结果 弹框顶部 VIP等级 筛选值应与被点击的 VIP 等级一致。例如点击 VIP2，筛选值应显示 VIP2 或等级 2。
实际结果 点击 VIP1 成员数量，弹框行内 VIP等级 = 1，但顶部筛选显示 VIP0。
点击 VIP2 成员数量，弹框行内 VIP等级 = 2，但顶部筛选显示 VIP1。
列表数据未观察到串用，但筛选展示值与当前等级错位。
