BUG-001：查看会员弹框 VIP 等级筛选显示比列表等级少 1

建议级别Major / P1
环境UAT 后台：http://site.bx-tytest.xyz/#/member/level；路径：福利中心 / VIP管理 / 查看会员；站点：巴西站-测试；商户：888。
前置条件后台已登录，当前页面存在成员数量非 0 的 VIP 等级行；执行仅限低敏只读查看与截图。
影响范围成员数量非 0 时打开的“查看会员/成员明细”弹框等级上下文。若筛选等级显示错位，运营人员会误判当前查看的 VIP 等级，并影响成员数量与明细数据一致性核对。
复现路径
  1. 进入后台 福利中心 / VIP管理 / 查看会员 页面。
  2. 确认列表中 VIP1 行成员数量为 458，且数字为蓝色可点击状态。
  3. 点击 VIP1 行成员数量 458。
  4. 查看弹框上方 VIP 等级筛选显示值，并对比弹框表格中会员行的 VIP等级列。
  5. 补充交叉观察：点击 VIP10 行成员数量 0 后，弹框筛选区显示 VIP9，表现为同类 off-by-one 错位。
实际结果点击 VIP1 成员数量后，弹框表格内会员 VIP等级为 1，但弹框筛选区显示 VIP0；点击 VIP10 的 0 后弹框筛选区显示 VIP9。
期望结果点击某一 VIP 等级的成员数量后，成员明细弹框应保持同一等级上下文：点击 VIP1 应显示 VIP1 并展示 VIP等级为 1 的会员；点击 VIP10 应显示 VIP10。弹框筛选显示不得比列表等级少 1。
截图证据
残余不确定性当前只读页面未提供后端数据基准，无法确认错位仅为筛选标签显示错误，还是请求参数/查询条件也存在等级偏移；建议开发同时核对弹框打开时传入的 VIP level 参数与展示标签映射。

BUG-002：成员数量为 0 仍显示为可点击蓝色按钮，点击后弹出成员明细

建议级别Major / P1
环境UAT 后台：http://site.bx-tytest.xyz/#/member/level；路径：福利中心 / VIP管理 / 查看会员；站点：巴西站-测试；商户：888。
前置条件后台已登录；列表中 VIP10 行成员数量为 0；执行仅限低敏只读查看与截图。
影响范围所有成员数量为 0 的 VIP 等级行。该行为直接违反“0 不可点击，点击不应出现弹框”的验收规则，会造成无效弹框和错误等级上下文。
复现路径
  1. 进入后台 福利中心 / VIP管理 / 查看会员 页面。
  2. 定位到 VIP10 行，确认成员数量为 0。
  3. 观察 0 的样式和鼠标状态。
  4. 点击 VIP10 行成员数量 0。
  5. 观察是否弹出成员明细弹框。
实际结果VIP10 的成员数量 0 显示为蓝色按钮，鼠标为 pointer；点击后弹出成员明细弹框，弹框筛选区显示 VIP9 且暂无数据。
期望结果成员数量为 0 时，不应显示为蓝色可点击状态；点击 0 不应触发任何成员明细弹框。

截图证据：点击后
