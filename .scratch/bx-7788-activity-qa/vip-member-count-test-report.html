需求点总结

需求点 产品规则 验收口径
入口 在 福利中心 / VIP管理 下增加 查看会员 tab。 进入 VIP管理 后能看到并切换到 查看会员 tab。
列表顺序 列表按照 VIP 等级从低到高显示。 VIP1、VIP2、VIP3... 按升序展示。
VIP等级 显示 VIP 等级，读取 VIP 配置。例如 VIP1 显示 1，VIP2 显示 2，VIP3 显示 3。 列表等级展示与 VIP 配置一致。
成员数量 显示该 VIP 等级有多少会员数量。 数量是数字；非 0 数量可点击；点击后弹框总数应与数量一致。
查看会员弹框 点击成员数量后弹出查看会员弹框，展示该等级里面所有状态的会员。 弹框会员属于被点击等级；不应串到其他 VIP 等级。
0 成员数量 成员数量为 0 时不可点击，点击不会出现弹框。 0 数量不应表现为可点击状态，也不应出现弹框。
