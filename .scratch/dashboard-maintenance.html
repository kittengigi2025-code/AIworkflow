Dashboard 维护说明

目标：新增需求时不再复制粘贴大段 HTML，只维护结构化数据。

文件分工

文件职责
data/qa-dashboard.json唯一的 Dashboard 数据源：需求、关注项、下载包、维护规则。
qa-dashboard-app.html很薄的页面壳，只负责挂载 CSS、JS 和页面容器。
site-assets/dashboard.js读取 JSON、渲染指标、筛选、列表、下载包。
site-assets/dashboard.cssDashboard 样式。
scripts/publish-qa-site.mjs发布前校验：统计需求、校验链接、发现死链直接失败。

新增需求流程

步骤动作
1把正式报告、Bug 单、证据放入对应需求目录。
2在 data/qa-dashboard.json 的 requirements 数组新增一条记录。
3如有新下载包，在 packages 数组新增一条记录。
4运行 npm run qa:publish。
5脚本通过后，再把链接发给项目组。
