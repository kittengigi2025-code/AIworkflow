QA 站点分享说明

这页只解决一个问题：不同对象应该看哪个入口。

分享路径

对象 推荐入口 说明
你自己 qa-home.html 总入口，后续所有需求、报告、Bug 包都从这里进。
项目组内网成员 http://10.0.120.150:8768/qa-home.html 完整内部站点，含 UAT 线索、截图、人员和下载包。
ZeroTier 网络成员 http://10.92.75.221:8768/qa-home.html 如果对方不在同网段但在 ZeroTier，可以试这个地址。
非项目成员 / 汇报展示 脱敏展示版 不含地址、账号、人员姓名、内部截图，适合贴到 Lark 文档。
开发修 Bug Bug 包 包含开发需要的缺陷单和证据截图，适合单独发送。

启动命令

本机查看：.\start-docs-server.ps1

内网分享：.\start-docs-server.ps1 -Lan -Port 8768

如果同事打不开，优先检查 Windows 防火墙是否允许 Node.js 入站访问。
